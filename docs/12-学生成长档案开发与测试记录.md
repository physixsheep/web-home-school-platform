# 学生成长档案开发与测试记录

> 日期：2026-11-26  
> 阶段：特色业务模块  
> 结论：五类成长记录、班主任维护、家长可见控制和附件鉴权已完成并通过回归测试

## 1. 已完成功能

### 1.1 成长记录分类

- 学习表现：`STUDY`
- 德育表现：`MORAL`
- 校园活动：`ACTIVITY`
- 荣誉奖励：`HONOR`
- 综合评价：`COMPREHENSIVE`

### 1.2 班主任维护

- 选择本班学生创建成长记录。
- 设置标题、内容、分类和发生日期。
- 设置家长是否可见。
- 上传图片或相关附件。
- 编辑本人创建的成长记录。
- 删除本人创建的成长记录。
- 不能为其他班级学生创建成长记录。
- 非班主任教师访问返回 HTTP 403。
- 已创建记录不能转移给其他学生。
- 发生日期不能晚于今天。

### 1.3 学生、家长与管理员

- 学生查看本人全部成长记录。
- 家长必须选择绑定孩子。
- 家长只能看到 `visible_to_parent = 1` 的记录。
- 家长不能下载“仅校内可见”记录的附件。
- 管理员查看全校成长档案，并可维护已有记录。
- 支持按分类、关键词、学生和日期范围查询。

### 1.4 前端页面

管理员：

```text
/admin/growth-records
```

教师：

```text
/teacher/growth-records
```

学生：

```text
/student/growth-records
```

家长：

```text
/parent/growth-records
```

学生和家长页面使用时间线展示成长记录，教师页面使用管理表格和编辑弹窗。

## 2. 后端接口

| 方法 | 路径 | 权限 |
|---|---|---|
| GET | `/api/growth-records` | 学生本人、家长绑定孩子、管理员全校 |
| GET | `/api/growth-records/manage` | 班主任 |
| GET | `/api/growth-records/options/students` | 班主任、管理员 |
| GET | `/api/growth-records/{id}` | 记录可访问者 |
| POST | `/api/growth-records` | 班主任 |
| PUT/DELETE | `/api/growth-records/{id}` | 记录教师或管理员 |

重点通过场景：

2. 非班主任教师创建记录返回 HTTP 403。

## 5. 当前限制

1. 成长记录当前未提供自定义分类。
2. 附件图片通过鉴权下载查看，尚未实现浏览器内图片画廊。
3. 无逐次编辑历史，只保留当前内容和更新时间。
4. 管理员可修改已有记录，但不能以管理员身份创建教师记录。
5. 家长可见开关只影响家长，不影响学生本人。
