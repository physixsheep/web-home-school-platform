# 家校互动管理开发与测试记录

> 日期：2026-11-26  
> 阶段：家校协同业务模块  
> 结论：留言发起、教师收件箱、双方回复、关闭和管理员审计已完成并通过回归测试

## 1. 已完成功能

### 1.1 学生与家长

- 选择学生当前班级的班主任或任课教师发起留言。
- 家长必须选择已绑定孩子。
- 家长不能为未绑定孩子发起留言。
- 学生只能以本人身份发起留言。
- 查看自己发起的留言列表。
- 查看教师回复并继续回复。
- 查看已读、已回复和已关闭状态。
- 按主题、内容及状态筛选。

### 1.2 教师

- 查看本人接收的留言收件箱。
- 未读留言优先展示。
- 打开会话时标记已读。
- 回复家长或学生留言。
- 家长或学生继续回复后，会话重新标记为未读。
- 关闭留言会话。
- 不能查看非本人接收的会话。

### 1.3 管理员

- 查看全校家校互动记录。
- 按发送人、学生、主题、内容和状态筛选。
- 审计视图为只读。

### 1.4 前端页面

管理员：

```text
/admin/messages
```

教师：

```text
/teacher/messages
```

学生：

```text
/student/messages
```

家长：

```text
/parent/messages
```

采用普通 HTTP 请求，不引入 WebSocket。

## 2. 后端接口

| 方法 | 路径 | 权限 |
|---|---|---|
| GET | `/api/messages/mine` | 学生、家长 |
| GET | `/api/messages/received` | 教师、管理员 |
| GET | `/api/messages/options/teachers` | 学生、家长 |
| GET | `/api/messages/{id}` | 参与方、管理员 |
| POST | `/api/messages` | 学生、家长 |
| POST | `/api/messages/{id}/read` | 接收教师 |
| POST | `/api/messages/{id}/replies` | 参与方 |
| POST | `/api/messages/{id}/close` | 接收教师 |

| 表 | 用途 |
|---|---|
| `interaction_message` | 留言会话主表 |
| `message_reply` | 留言回复 |

SQL：

```text
database/13_interaction_schema.sql
```

重点通过场景：

1. 家长查询孩子当前班级教师选项。
2. 学生向本班教师发起留言。
3. 家长为绑定孩子发起留言。
4. 学生向非本班教师留言返回 HTTP 403。
5. 家长为未绑定孩子留言返回 HTTP 403。
6. 教师收件箱显示新留言。
7. 教师标记已读并回复。
8. 家长查看教师回复。
9. 家长继续回复后，会话重新变为未读。
10. 非会话教师查看详情返回 HTTP 403。
11. 教师关闭会话后继续回复返回 HTTP 409。
12. 管理员查看全校留言审计。
13. 此前所有模块回归测试继续通过。

## 5. 当前限制

1. 本期使用普通 HTTP 刷新，不提供实时消息推送。
2. 会话关闭后不能重新打开。
3. 留言暂不支持附件。
4. 管理员审计视图只读。
5. 教师权限基于接收教师本人，不按班级自动扩大访问。
