## 1. 本次完成内容

### 1.1 用户与人员

- 用户分页查询，支持账号、姓名、手机号、工号/学号搜索。
- 按角色和账号状态筛选。
- 新增用户。
- 创建教师、学生、家长时同步建立对应人员档案。
- 教师创建时校验工号，学生创建时校验学号。
- 更新姓名、手机号和邮箱。
- 启用或禁用账号。
- 禁用账号时递增 Token 版本，使旧 Token 立即失效。
- 重置密码并撤销旧 Token。
- 查询四类系统角色。

用户页面：

```text
/admin/users      全部用户
/admin/teachers   教师管理
/admin/students   学生管理
/admin/parents    家长管理
```

### 1.2 年级和班级

- 年级分页、新增、编辑、删除。
- 年级名称和层级参数校验。
- 已有班级的年级禁止删除。
- 班级分页、新增、编辑、删除。
- 班级列表实时统计当前学生人数和有效教师关联数。
- 仍有关联教师或学生班级履历的班级禁止删除。

页面：

```text
/admin/grades
/admin/classes
```

### 1.3 家长学生绑定

- 绑定关系分页查询。
- 支持家长、学生、学号和绑定状态筛选。
- 管理员新增绑定并同步记录核验人和核验时间。
- 一名学生只能有一名主要联系人。
- 支持撤销和恢复绑定。
- 已撤销的绑定再次新增时复用原记录。

页面：

```text
/admin/parent-bindings
```

### 1.4 教师任课

- 教师班级关联分页查询。
- 创建班主任关联。
- 创建学科任课关联。
- 班主任关联不能填写学科。
- 同一班级同时只能有一名有效班主任。
- 同一教师不能重复任教同一班级的同一学科。
- 支持结束关联并保留历史记录。

页面：

```text
/admin/teacher-assignments
```

### 1.5 学生分班与履历

- 查询学生当前和历史班级。
- 首次分班。
- 办理调班。
- 调班时自动结束旧履历，并保留原班信息。
- 同一学生不能拥有两个当前班级。
- 目标班级和开始日期在后端校验。

页面：

```text
/admin/student-classes
```

## 2. 后端接口

所有接口位于 `/api/admin/**`，使用：

```java
@PreAuthorize("hasRole('ADMIN')")
```

### 2.1 用户

| 方法 | 路径 | 功能 |
|---|---|---|
| GET | `/api/admin/users` | 用户分页与筛选 |
| GET | `/api/admin/roles` | 角色选项 |
| POST | `/api/admin/users` | 新增用户及人员档案 |
| PUT | `/api/admin/users/{id}` | 更新用户基础资料 |
| PATCH | `/api/admin/users/{id}/status` | 启用或禁用 |
| POST | `/api/admin/users/{id}/reset-password` | 重置密码 |

### 2.2 年级与班级

| 方法 | 路径 | 功能 |
|---|---|---|
| GET / POST | `/api/admin/grades` | 年级分页、创建 |
| PUT / DELETE | `/api/admin/grades/{id}` | 更新、删除 |
| GET / POST | `/api/admin/classes` | 班级分页、创建 |
| PUT / DELETE | `/api/admin/classes/{id}` | 更新、删除 |

### 2.3 关系

| 方法 | 路径 | 功能 |
|---|---|---|
| GET / POST | `/api/admin/parent-bindings` | 绑定分页、创建 |
| PATCH | `/api/admin/parent-bindings/{id}/status` | 撤销或恢复 |
| GET / POST | `/api/admin/teacher-assignments` | 任课分页、创建 |
| PATCH | `/api/admin/teacher-assignments/{id}/end` | 结束关联 |
| GET / POST | `/api/admin/student-classes` | 分班分页、分班或调班 |

### 2.4 下拉选项

| 路径 | 内容 |
|---|---|
| `/api/admin/options/teachers` | 有效教师 |
| `/api/admin/options/students` | 有效学生 |
| `/api/admin/options/parents` | 有效家长 |
| `/api/admin/options/classes` | 有效班级 |
| `/api/admin/options/subjects` | 有效学科 |

## 3. 数据权限与业务保护

- 只有 `ADMIN` 角色可访问管理员组织人员接口。
- 学生使用有效 Token 请求管理员用户列表返回 HTTP 403。
- 禁用账号后无法重新登录。
- 禁用账号和重置密码会递增 `token_version`。
- 用户、工号、学号、手机号、年级名称、班级组合等由数据库唯一约束兜底。
- 班级删除和年级删除执行关联引用检查。
- 家长绑定、教师任课和学生调班使用事务。
- 教师任课创建时锁定班级记录，学生分班时锁定学生记录，防止并发请求同时通过唯一性检查。
- 前端不保存固定业务列表，所有列表和选项均来自后端数据库。

## 6. 当前限制

1. 四类角色作为系统固定角色，本期未开放自定义角色和细粒度权限点编辑。
2. 用户编辑目前限于姓名、手机号和邮箱，工号/学号等档案字段调整留待人员档案详情页。
3. 教师任课目前采用“结束后重新创建”方式，未提供直接修改历史记录。
4. 学生分班不允许未来开始日期倒序调整；如录入错误，需后续增加履历纠错功能。
5. 前端生产构建仍有 Element Plus 公共依赖块偏大的提示，功能不受影响。
