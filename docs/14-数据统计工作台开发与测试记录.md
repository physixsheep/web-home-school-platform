# 数据统计工作台开发与测试记录

> 日期：2026-11-26  
> 阶段：统计分析与首页完善  
> 结论：管理员与教师工作台真实统计数据、ECharts 图表和角色隔离已完成

## 1. 管理员工作台

实时指标：

- 全校在读学生人数。
- 在职教师人数。
- 家长用户人数。
- 启用班级数量。
- 已发布通知数量。
- 待审批请假数量。

图表：

- 各年级当前学生分布环形图。
- 已发布通知按全校、年级、班级范围统计柱状图。

数据来源：

```text
student
teacher
parent
school_class
notice
leave_request
student_class
grade
```

## 2. 教师工作台

实时指标：

- 本人当前有效关联班级数量。
- 关联班级当前学生人数。
- 已发布或已关闭作业数量。
- 作业提交率。
- 待批改提交数量。
- 班主任待审批请假数量。

提交率口径：

```text
累计实际提交数 / Σ(各班级当前学生数 × 各班级作业数) × 100%
```

图表：

- 各班级学生人数与累计提交量分组柱状图。
- 待批改作业与待审批请假柱状图。

班级概况表：

- 年级和班级名称。
- 当前学生人数。
- 已发布作业数量。
- 累计作业提交数量。

## 3. 后端接口

| 方法 | 路径 | 权限 |
|---|---|---|
| GET | `/api/dashboard/admin` | 管理员 |
| GET | `/api/dashboard/teacher` | 教师 |

管理员与教师工作台替换了原基础认证首页，路由仍为：

```text
/admin/home
/teacher/home
```

## 4. 前端实现

- Vue 3 组合式 API 请求真实统计接口。
- Element Plus 指标卡、进度条和班级表格。
- Apache ECharts 6.1.0 环形图与柱状图。
- 图表在窗口大小变化时自动重绘。
- 页面跳转按钮复用现有业务模块。
- 无固定业务假数据。

## 6. 当前限制

1. 提交率使用当前班级人数作为历史作业应缴人数，学生大范围调班时可能需要按快照优化。
2. 工作台目前不做自动轮询，需要刷新页面获取最新数据。
3. 管理员暂无按日期区间统计的趋势图。
4. 统计接口未做缓存，数据量较大后可按验收规模评估缓存或预聚合。
