## 4. 权限验收

已验证：

- 学生不能访问管理员接口。
- 家长不能访问未绑定孩子数据。
- 教师不能操作无关班级或学科。
- 任课教师不能代替班主任审批请假。
- 非班主任不能维护成长档案。
- 非会话教师不能读取留言。
- 普通用户不能读取操作日志。
- 禁用账号和重置密码会使旧 Token 失效。

## 6. 已知限制

- 四类系统角色固定，尚未提供自定义权限点编辑器。
- 本期未实现 WebSocket 实时消息。
- 成绩 Excel 批量导入未实现。
- 附件仅使用本地目录，生产建议对象存储。
- 操作日志同步写入，数据量大后可转异步。
- 前端 Element Plus 与 ECharts 公共依赖仍有较大的构建块提示，不影响运行。
- 自动化覆盖以 API 烟雾测试和构建为主，浏览器端人工验收清单仍需在最终演示环境执行。
