# 本地与单机部署说明

## 1. 运行环境

| 组件 | 要求 |
|---|---|
| JDK | 17 |
| MySQL | 8.0+ |
| Node.js | 20.19+、22.12+ 或 24 |
| pnpm | 11+ |
| Nginx | 可选，生产静态资源与反向代理 |

本项目使用 Spring Boot 内嵌 Tomcat，后端通过可执行 JAR 启动。

## 2. 初始化数据库

推荐一次执行：

```powershell
mysql --default-character-set=utf8mb4 -u root -p -e "source database/init_all.sql"
```

如已有数据库并逐步升级，按 `database/README.md` 的顺序执行。

## 3. 后端环境变量

| 变量 | 说明 |
|---|---|
| `DB_URL` | MySQL JDBC URL |
| `DB_USERNAME` | 数据库账号 |
| `DB_PASSWORD` | 数据库密码 |
| `SERVER_PORT` | 后端端口，默认 8080 |
| `JWT_SECRET` | Base64 编码的 JWT 密钥，生产必须替换 |
| `JWT_EXPIRATION_MINUTES` | Token 有效期 |
| `UPLOAD_ROOT` | 私有附件目录 |

生产环境示例：

```powershell
$env:DB_URL='jdbc:mysql://127.0.0.1:3306/home_school_platform?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&allowPublicKeyRetrieval=true&useSSL=false'
$env:DB_USERNAME='home_school_app'
$env:DB_PASSWORD='请使用实际密码'
$env:SERVER_PORT='8080'
$env:JWT_SECRET='请替换为至少32字节随机值的Base64编码'
$env:UPLOAD_ROOT='D:\home-school-storage'
```

启动：

```powershell
$env:JAVA_HOME='C:\Users\liu\.jdks\ms-17.0.17'
& "$env:JAVA_HOME\bin\java.exe" -jar backend\home-school-platform.jar
```

## 4. 前端

开发：

```powershell
pnpm --dir frontend install
pnpm --dir frontend dev
```

生产构建：

```powershell
pnpm --dir frontend build
```

构建结果位于：

```text
frontend/dist
```

单机 Nginx 示例见 `deploy/nginx.conf.example`。必须将 `/api` 反向代理到 Spring Boot，并保留 `X-Forwarded-For`。

## 5. 附件目录

- `storage/upload` 仅保存私有文件。
- 不要通过 Nginx 直接暴露该目录。
- 附件下载统一经过 `/api/files/{id}/download` 鉴权。
- 生产环境建议迁移至对象存储或受控共享存储。

## 6. 安全配置

- 替换开发 JWT 密钥。
- 修改所有测试账号密码。
- 数据库使用最小权限业务账号，不使用 `root`。
- 生产环境限制 Swagger UI 访问。
- 配置 HTTPS。
- 设置日志和附件定期备份。

## 7. 一键打包

```powershell
.\scripts\package.ps1
```

将在 `release/` 下生成包含后端 JAR、前端 dist、SQL、文档和部署示例的 ZIP。
