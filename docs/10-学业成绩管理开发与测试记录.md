# 学业成绩管理开发与测试记录

> 日期：2026-11-26  
> 阶段：核心业务开发第三模块  
> 结论：考试、学科、成绩录入、统计报告和 ECharts 图表已完成并通过回归测试

## 1. 已完成功能

### 1.1 管理员

- 考试分页查询。
- 按考试名称、状态和学年筛选。
- 创建、修改和删除考试。
- 支持年级范围或指定班级范围。
- 校验考试班级属于所选年级。
- 已录入成绩的考试禁止删除。
- 学科分页、创建、修改和删除。
- 学科编码、名称和默认满分维护。
- 已有成绩或教师关联的学科禁止删除。

### 1.2 教师

- 查询可录入成绩的已发布考试。
- 只显示本人有效任教的班级和学科。
- 选择考试、班级和学科后加载当前班级学生。
- 支持成绩、缺考和备注录入。
- 支持批量保存。
- 重复保存执行更新，不产生重复成绩。
- 校验成绩范围 `0..学科默认满分`。
- 校验缺考与分数互斥。
- 教师不能访问未任教班级或学科。
- 查看班级单科已录人数、平均分、最高分、最低分和缺考人数。

### 1.3 学生与家长

- 学生查看本人已发布考试成绩。
- 家长必须选择绑定孩子。
- 家长不能查看未绑定孩子成绩。
- 按学年筛选成绩。
- 查看每次考试的各学科成绩、满分和班级快照。
- 查看考试总分和学科平均分。
- 查看历次考试总分趋势图。
- 查看最近一次考试的学科柱状图。

## 3. 数据库变更

新增：

| 表 | 用途 |
|---|---|
| `examination` | 考试信息 |
| `score` | 学生考试成绩 |

SQL：

```text
database/07_score_schema.sql
database/08_score_data.sql
```

成绩使用唯一约束：

```text
exam_id + student_id + subject_id
```

重复保存使用 MySQL `ON DUPLICATE KEY UPDATE`，保证同一学生同一考试同一学科只有一条成绩。

## 5. 当前限制

1. 当前总分按已录入学科直接求和，尚未按不同满分统一折算。
2. 班级排名未持久化，也尚未展示个人年级排名。
3. 成绩批量导入 Excel 作为扩展功能，本期未实现。
4. 成绩修改仅记录 `updated_by` 和更新时间，没有逐次修改历史。
5. 考试状态不会按日期自动归档，需要管理员维护。
