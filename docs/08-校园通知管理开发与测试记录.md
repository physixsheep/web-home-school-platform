# 校园通知管理开发与测试记录

> 日期：2026-11-26  
> 阶段：核心业务开发第一模块  
> 结论：通知、已读记录和附件鉴权流程已完成，构建与 MySQL 端到端测试通过

## 1. 已完成功能

### 1.1 通知发布与管理

- 管理员创建全校、年级和班级通知。
- 本班有效任课教师创建本班通知。
- 教师不能创建全校或年级通知。
- 通知草稿保存。
- 草稿发布。
- 已发布通知编辑。
- 已发布通知撤回。
- 草稿删除。
- 管理员可管理所有通知。
- 教师只能管理本人发布的通知。

### 1.2 通知阅读

- 已登录用户分页查看自己有权阅读的已发布通知。
- 学生按本人当前班级读取。
- 家长按有效绑定孩子的当前班级读取。
- 教师按有效任教班级读取。
- 管理员可阅读全部已发布通知。
- 打开通知后写入已读记录。
- `notice_id + user_id` 唯一，重复标记已读保持幂等。
- 管理员和发布教师可查看阅读名单。

### 1.3 附件

- 管理员和教师可上传附件。
- 文件最大 20 MB。
- 允许图片、PDF、Office 文档和 TXT。
- 文件以随机名称保存在私有目录。
- 数据库记录原始文件名、扩展名、MIME、大小和 SHA-256。
- 临时附件只能由上传者下载。
- 通知创建或保存时绑定附件。
- 通知附件下载重新执行通知可见性校验。
- 撤回通知后，普通学生和家长不能再下载附件。
- 取消编辑时清理未提交的临时附件。

## 6. 当前限制

1. 通知正文当前按纯文本保存和展示，尚未开放富文本编辑器。
2. 附件存储在本地私有目录；生产环境建议替换为对象存储。
3. 通知撤回后不能直接恢复，需要重新创建或后续增加恢复状态。
4. 阅读名单当前仅显示已读用户，不显示“应读未读”名单。
5. 临时附件物理文件在标记删除后不立即清理，后续增加定期清理任务。
