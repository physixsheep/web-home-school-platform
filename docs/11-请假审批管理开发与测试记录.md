# 请假审批管理开发与测试记录

> 日期：2026-11-26  
> 阶段：核心业务开发第四模块  
> 结论：学生请假、班主任审批、撤销、家长查询和证明附件已完成并通过回归测试

## 1. 已完成功能

### 1.1 学生请假

- 病假、事假和其他三种类型。
- 设置开始时间、结束时间和请假原因。
- 上传证明附件。
- 提交后状态为待审批。
- 同一学生时间重叠的待审批或已批准申请禁止重复提交。
- 请假时长至少 30 分钟。
- 学生只能对本人待审批申请执行撤销。

### 1.2 班主任审批

- 查询本人当前班主任班级的请假。
- 待审批记录优先展示。
- 支持批准和驳回。
- 必须填写审批意见。
- 审批时保存审批教师、审批时间和意见。
- 当前班主任身份在提交审批时重新校验。
- 使用状态和版本条件更新，防止重复审批或并发覆盖。
- 非班主任任课教师不能审批。

### 1.3 家长与管理员

- 家长必须选择绑定孩子后查看请假记录。
- 家长不能查看未绑定孩子的请假。
- 家长可查看审批状态、意见和证明附件。
- 管理员可查看全校请假记录，但不能代替班主任审批。

## 2. 后端接口

| 方法 | 路径 | 权限 |
|---|---|---|
| GET | `/api/leaves` | 学生本人、家长绑定孩子、管理员全校 |
| GET | `/api/leaves/approval` | 当前班主任 |
| GET | `/api/leaves/{id}` | 请假申请可访问者 |
| POST | `/api/leaves` | 学生 |
| POST | `/api/leaves/{id}/cancel` | 申请学生 |
| POST | `/api/leaves/{id}/decision` | 当前班主任 |

重点通过场景：

1. 学生上传请假证明并提交请假。
2. 时间重叠的第二次请假返回 HTTP 409。
3. 班主任审批列表显示待审批申请。
4. 非班主任教师尝试审批返回 HTTP 403。
5. 当前班主任批准请假。
6. 同一请假再次审批返回 HTTP 409。
7. 学生查看最新批准结果。
8. 家长查看绑定孩子请假记录并下载证明附件。
9. 学生创建并撤销另一条待审批请假。
10. 管理员查看全校请假记录。
11. 认证、组织、通知、作业和成绩回归全部通过。

## 5. 当前限制

1. 请假申请提交后不支持学生编辑，只能撤销后重新提交。
2. 审批意见目前为必填，不能只点击批准而不填写意见。
3. 系统不自动按请假时间校验到校状态。
4. 管理员仅查看请假记录，不提供代班主任审批。
5. 请假证明附件标记删除后，物理文件由后续清理任务处理。
